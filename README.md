# Student Performance Tracker

## About the Project

The Student Performance Tracker is a Python-based application developed to manage student academic records and analyse their performance. It combines a database-driven student management system with an analytics component that generates visual reports to help interpret academic results.

## Features

- Manage student academic records.
- Store and retrieve student information using a database.
- Analyse student marks and performance.
- Calculate average marks per student.
- Display grade distribution.
- Generate a bar graph showing average marks by student.
- Generate a pie chart illustrating grade distribution.

## Project Files

| File | Description |
|---|---|
| `student tracker.py` | Main application for managing student records. |
| `analytics.py` | Analyses student performance data and generates visual reports. |

## Technologies Used

- Python
- SQLite3
- Tkinter
- Pandas
- Matplotlib

## How to Run

1. Ensure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Install the required external libraries:

```bash
pip install pandas matplotlib
```

5. Run the main application:

```bash
python "student tracker.py"
```

6. Run the analytics script separately when required:

```bash
python analytics.py
```

## Analytics and Visualisation

The analytics component generates visual reports, including:

- Average Mark by Student – Bar Graph.
- Grade Distribution – Pie Chart.
